\# Лабораторная работа № 1 — Todo List



\## Описание проекта



Приложение Windows Forms для управления списком задач. Позволяет добавлять задачи, изменять их названия, отмечать выполнение и удалять задачи.



\## Реализованные возможности



\- Добавление задач.

\- Переименование и удаление задач.

\- Отметка задач как выполненных.

\- Установка срока выполнения.

\- Сохранение и загрузка задач в формате JSON.

\- Поиск задач по мере ввода текста.

\- Фильтрация: все задачи, активные и выполненные.

\- Сортировка задач по сроку выполнения.

\- Выделение просроченных невыполненных задач красным цветом.



\## Технологии



\- C#

\- .NET 10

\- Windows Forms

\- JSON для хранения данных



\## Структура проекта



\- `Models/TodoItem.cs` — модель задачи.

\- `Services/TodoList.cs` — управление списком задач и сохранением данных.

\- `Form1.cs` — интерфейс и обработка действий пользователя.

\- `Program.cs` — точка входа приложения.



\## Запуск



1\. Открыть файл `Lab1Todo.csproj` в Visual Studio.

2\. Убедиться, что установлен .NET 10 SDK.

3\. Запустить приложение клавишей `F5`.



\## Проверка работы



Проверены добавление, переименование, удаление и выполнение задач, поиск, фильтрация, сохранение и загрузка после перезапуска приложения. Просроченные невыполненные задачи выделяются красным цветом.
