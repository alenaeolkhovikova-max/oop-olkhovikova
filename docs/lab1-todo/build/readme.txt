# Лабораторная работа 1: Список задач (Todo List)

## Автор
Ольховикова А.Е., группа ИИ(4)

## Описание
Консольное приложение для управления списком задач с сохранением в JSON.

## Возможности
- Добавление задач с названием и сроком
- Отметка выполненных задач
- Переименование задач
- Удаление задач
- Автоматическое сохранение в файл tasks.json
- Загрузка при запуске
