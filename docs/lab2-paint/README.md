# Лабораторная работа №2. Графический редактор
## Описание проекта

Графический редактор — приложение для создания простых рисунков с помощью графических примитивов.

Проект разработан на языке C# с использованием Windows Forms и .NET 10.

## Реализованные возможности

- Рисование карандашом.
- Рисование прямых линий.
- Рисование прямоугольников.
- Рисование эллипсов.
- Выбор цвета фигур.
- Настройка толщины линий.
- Визуальное выделение выбранного инструмента.
- Отмена последнего действия с помощью кнопки и Ctrl + Z.
- Очистка холста.
- Сохранение рисунка в JSON-файл.
- Загрузка рисунка из JSON-файла.

## Структура проекта

- `Controls` — элементы управления, включая холст для рисования.
- `Models` — классы для хранения рисунка и данных фигур.
- `Shapes` — базовый класс Shape и классы конкретных фигур.
- `Form1.cs` — главное окно приложения.
- `Program.cs` — точка входа программы.

## Используемые технологии

- C#
- .NET 10
- Windows Forms
- System.Drawing
- System.Text.Json

## Запуск проекта

Для запуска необходим Windows и установленный .NET 10 SDK.

Из корневой папки репозитория выполните команду:

```powershell
dotnet run --project docs/lab2-paint
```

## Результат

Разработано оконное приложение, позволяющее создавать рисунки, редактировать их, отменять последнее действие и сохранять результаты в JSON-файл.
